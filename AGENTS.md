## Agent skills

### Issue tracker

As tarefas e especificações ficam no GitHub Issues de `luz-da-esperanca/ERP`. Antes de consultar ou publicar tickets, leia `docs/agents/issue-tracker.md`.

A triagem usa as cinco labels padrão. Antes de classificar issues, consulte o mapeamento em `docs/agents/triage-labels.md`.

### Domain docs

Layout `single-context`: `GLOSSARY.md` na raiz e ADRs em `docs/adr/`. Antes de explorar o domínio, siga `docs/agents/domain.md`.
