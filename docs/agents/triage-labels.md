# Labels de triagem

As skills usam cinco papéis de triagem. Esta tabela define as labels correspondentes no GitHub Issues deste repositório.

| Papel na skill | Label no rastreador | Significado |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A manutenção precisa avaliar a issue. |
| `needs-info` | `needs-info` | Aguarda mais informações de quem abriu a issue. |
| `ready-for-agent` | `ready-for-agent` | Especificação suficiente para implementação autônoma por um agente. |
| `ready-for-human` | `ready-for-human` | Exige implementação humana. |
| `wontfix` | `wontfix` | A issue não será implementada. |

Quando uma skill mencionar um papel de triagem, use a label correspondente desta tabela. Para adotar outros nomes, edite a coluna “Label no rastreador”.
